# Rewire 神經可塑性｜3D 互動導讀

以中文介紹 Nicole Vignola 著、梁永安譯的《Rewire－神經可塑性》。本版在 [rewire-neuroplasticity-story](https://github.com/laierin615/rewire-neuroplasticity-story) 的 React 網站上進行本地優化，加入真正可旋轉的 Three.js 立體動畫、明亮配色及完整原章導讀。參考版本：`b9b5fec5fec69e21aaf144ef7d819216423497c5`。

## 開啟已建置網站

隨附的 `rewire-3d-guide` 資料夾含完整靜態網站，無須安裝前端套件：

在 macOS 可直接雙擊資料夾中的 `啟動網站.command`，會自動啟動服務並開啟瀏覽器。也可手動啟動：

1. 在該資料夾開啟終端機。
2. 執行 `python3 -m http.server 8766 --bind 127.0.0.1`。
3. 用瀏覽器開啟 `http://localhost:8766/`。

雙擊啟動時若 8766 已被占用，會自動改用下一個可用埠號，終端機視窗會顯示實際網址；關閉該視窗即停止網站。手動啟動時若埠號被占用，改用 8767 等其他埠號。此版使用 JavaScript 模組，須透過本機 HTTP 服務開啟，不能只雙擊 `index.html`。首次載入後不需要外部圖片、網路字型、分析追蹤或 CDN；題庫的官方參考連結另需網路。

## 編輯原始專案

需要 Node.js 22.12 以上及網路（僅用於安裝套件）。沿用專案指定的 pnpm 10.4.1：

```sh
npx --yes pnpm@10.4.1 install --frozen-lockfile
npx --yes pnpm@10.4.1 dev
```

開啟 `http://localhost:4173/`。

```sh
npx --yes pnpm@10.4.1 check
npx --yes pnpm@10.4.1 build
npx --yes pnpm@10.4.1 preview --port 4174
```

正式前端輸出在 `dist/public/`；整個目錄可由一般靜態 HTTP 服務提供。保留原專案的 Express 啟動方式：建置後執行 `pnpm start`，預設埠號 3000。

## 網站架構

網站由上到下就是書籍導覽順序：

1. **書名與作者**：繁體中文版原書封面、作者與譯者，以及核心提問。
2. **全書地圖**：導言 → 擺脫負面情緒 → 改變你的敘事 → 增強積極性 → 尾聲。地圖下方是「全書核心」三張卡（核心提問／核心機制／核心方法），以及一行閱讀標示說明。
3. **導言**：可塑性、硬體／軟體、自動性、心理捷思，以及突觸傳訊的立體動畫。
4. **階段一**：壓力與調節動畫、原書壓力迴圈，接著依序呈現本階段各章；確認偏誤後接咖啡館注意力篩選模型。
5. **階段二**：重組潛意識、新路徑動畫，接著依序走過七個步驟。
6. **階段三**：韌性、成長型心態、肌肉、睡眠、多巴胺與自我信賴；肌腦軸、記憶鞏固與獎勵蹺蹺板的立體示意放在對應章節後。
7. **尾聲**：把理解接上下一次日常練習。
8. **教檢連結**：第一部分是「歷屆試題：腦區與學習」，依「01 腦區 → 02 考題 → 03 解答 → 04 書中概念」四站作答，最後一站可跳回對應原章。第二部分是「教檢深度問答」，分學習理論、認知與記憶、動機與心態、發展與大腦、情緒與輔導五組，每題並列「書中說法」與「教檢延伸」，附答題要點、容易混淆處、教學現場應用，以及相關歷屆試題。
9. **延伸資料**：概念庫、書中案例、腦區比較、主題深讀、章節搜尋、實作工具與教育連結。預設收合，需要時展開。

每一原章由上而下是：**小島情境動畫** → 「這章在說什麼」 → 「展開看更多」（重要概念、讀懂這一章、書中例子、動畫文字版）。書中內容不加標籤，只有本導讀另外補充的內容標「導讀補充」。有書中方法的章節另列步驟，並附「教檢連結」按鈕直接開啟對應深度問答。深度問答也可用網址 `#qa-<id>` 直接開啟，例如 `#qa-sleep-memory`。

正文在桌機為 20px、手機為 18px；操作文字也同步放大。原章摘要全部依原書順序顯示，各章可進入滿版解說。功能數量宣傳不出現在頁面中；README 保留內容數量以方便維護：導言 1、階段一 7、階段二 8、階段三 6、尾聲 1；深度問答 20 題，其中 13 題附 1–4 道相關歷屆試題。

## 小島情境動畫

介面與動畫採可愛療癒的小島風格：粉圓圓體（`@fontsource/huninn`，OFL 授權）、奶油色底、樹葉綠與膠囊按鈕。角色是原創的圓胖動物村民，不使用任何遊戲公司的角色或素材。

- 23 章各有一段情境劇（`client/src/data/islandScenes.ts`），角色用對話框演出書中的例子；最後一句「換你想想」接回該章的提問。作者是粉色上衣的兔子「妮可」，書中對讀者說的情境由角色「你」演出；科比、麥克斯是書中的狗。
- 台詞依原書改寫，原書沒寫的結果不補（例如健身房借硬幣只演到她提出請求）；非原書內容會在對話框標「導讀補充」。
- 操作：點畫面或對話框看下一句（打字中先顯示全文），也可用上一句、從頭、自動播放；鍵盤 Enter／空白鍵／← →。系統啟用減少動態效果時，走位直接到位、文字不跑打字機。
- 動畫接近視窗才建立 WebGL，離開即釋放；無法建立時仍可讀對話與文字版。
- 程式：`client/src/island/`（kit 共用色票與幾何、villager 角色與姿勢、props 道具、engine 場景執行），`client/src/components/IslandScene.tsx`（對話框與控制）。

## 書中例子與立體示意

原章旁新增 28 張案例／情境／練習／比喻／研究摘要，分布於 21 個章節。同章有多個例子時，用標題按鈕切換；所有例子均由上傳內文改寫，收在各章「展開看更多」裡。主閱讀順序不變，沒有案例與動畫數量宣傳。

例如：換手刷牙、咖啡館背景聲、作業期限、狗狗科比與嘆息、火車晚點、咬檸檬、喬許自嘲、薩曼莎與瑪莎姊妹、湯姆誤解笑聲、寶藍色 BMW、醫學院夢想、作者學網球、晨跑彩排、健身房借硬幣、原野與新路、菲爾普斯護目鏡進水、狗狗麥克斯、學新語言與疲倦、到達謬誤、出版社邀約。

## 3D 動畫與教學操作

- 拖曳模型或使用左右旋轉按鈕改變視角。
- 「暫停動畫」固定亮點；四個步驟可直接點選，右側同步顯示說明、觀察位置及提問。
- 「下一步」手動推進；勾選「自動換步」後，播放中每六秒推進一步。
- 「重播」回到第一步並重設視角，保留播放／暫停選擇。
- 壓力動畫下方可展開原書十環節的壓力迴圈（壓力 → 無能力應付情緒 → 焦慮 → 容易被觸發 → 高度警覺 → 延宕 → 扭曲的負面自我信念 → 低自尊 → 無能力把基本需要列為優先 → 無助益的應對機制 → 回到壓力）。
- 各原章的「滿版解說」支援 `←`／`→` 依全書順序換章、`Esc` 返回原位置。每章可切換「章節提綱／重點與工具」，有例子的章節另有「書中例子」，再用方向鍵按原書順序繼續。延伸資料另保留可搜尋與篩選的導讀介面。
- 手機採單欄；章節導覽可橫向滑動。系統啟用減少動態效果時，新 3D 動畫預設暫停。
- 3D 需支援 WebGL。若無法建立繪圖環境，仍顯示文字與四步導覽。模型接近視窗才建立繪圖環境；離開附近範圍會釋放資源，再回來時按目前步驟重新呈現，避免長頁同時占用多個 WebGL 環境。

## 資料來源與改寫策略

主要來源為使用者提供的 `Rewire-神經可塑性_全書完整內文.md`；EPUB 用作輔助參照。原始全書檔不放入網站或本次交付封裝。

新增 `guideChapters.ts` 的原章名稱、順序與重點以附件為依據；摘要、四格提綱、動畫旁白、概念庫及工具操作均為重整與改寫。生活問題及教學提問是導讀設計，不是作者逐字原文。特別保留〈騰出空間〉「在觸發與反應之間暫停」的意思，與戰略性休息分開說明。

原專案 `bookContent.ts` 的主題內容、案例與短引文予以保留。引文集中在該檔的 `bookQuotes`、`chapters.evidence`，以及首頁各區標題、引言與頁尾，以引號或 `blockquote` 區別；同一句可能重複用於標題。本次新增的完整原章導讀不收錄長段逐字內文。

教檢歷屆試題來自原專案 `examQuestions.ts`，官方題本連結保留在各題解答中；年份以民國年顯示。`examDeepQA.ts` 的「書中說法」依原書改寫，「教檢延伸」「答題要點」「容易混淆」「帶回教學現場」則是本導讀補充的教育心理學整理，不能視為本書內容或作者的主張。頁面上兩者分欄並列，避免混淆。

`chapterDepth.ts` 的每一點都標示來源類型；人物身分與情節已逐條對照原書內文（例如瑪莎被稱讚「聰明」、健身房借硬幣原書未寫結果、到達謬誤由 Tal Ben-Shahar 提出）。

模型的形狀、線粗、亮點、顏色及步驟時間都是解說符號，不表示真實解剖位置、測量數值、改善速度或療效。沿用原專案的生理指標動畫已明確標示數值為概念設定。首頁與書籍資料使用上傳 EPUB 內的 `OEBPS/image/Cover.jpg` 原書封面，未重繪或裁切。全書 EPUB 本身不放入網站封裝。

## 一小時導讀逐字稿

本機的 `導讀稿/` 逐字稿（Markdown 與 Word，未隨公開儲存庫上傳）搭配本網站使用，對象是對心理學有興趣、沒有神經科學背景的成人。共分六段：共鳴開場（00–06）、導言（06–14）、階段一（14–30）、階段二七步驟（30–46）、階段三（46–56）、回顧與小承諾（56–60）。每段標出網站位置、要展示的案例或 3D 模型與停在哪一步、互動時間、沒有人回應時的接話，以及轉場。照念部分約 7,800 中文字，以約 45 分鐘講述加 15 分鐘示範與互動設計。附錄有時間控制、冷場問句，以及例子出處與網站位置對照表。
